# 🚀 Teste Técnico – Estágio Ribeirão Preto

Este repositório contém as resoluções de 5 exercícios propostos como parte do processo seletivo para estágio na região de Ribeirão Preto. Os exercícios foram resolvidos utilizando a linguagem **Dart**, com foco em lógica de programação e estruturas de repetição.

## 🧠 Exercícios Resolvidos

1. **Verificador de número na sequência de Fibonacci**  
   - Recebe um número do usuário e identifica se ele pertence à sequência de Fibonacci.

2. **Contador de letras 'A' e 'a' em uma string**  
   - Solicita uma string do usuário e retorna a quantidade de letras **'A' (maiúsculas)** e **'a' (minúsculas)**.

3. **Soma acumulada com while até atingir 77**  
   - Realiza uma soma contínua até que o total chegue a 77, demonstrando o uso de estruturas de repetição.

4. **Manipulação de listas com estruturas de repetição**  
   - Conjunto de 6 exercícios usando listas e laços `for`, com foco em iteração, manipulação e análise de dados em arrays.

5. **Desafio dos interruptores e lâmpadas**  
   - Resolução lógica de um problema clássico de raciocínio, explicando como identificar qual interruptor controla qual lâmpada com no máximo duas idas às salas.

## Considerações:

Optei por utilizar Dart por ser uma linguagem moderna, com forte tipagem e estrutura clara, ideal para lógica e testes técnicos. Cada exercício foi implementado com foco em legibilidade, clareza e boas práticas.
